# Vinheria Agnello — Checkpoint 03

Sistema simples de controle de estoque de vinhos usando o console.log para exibir os vinhos cadastrados

## O que foi implementado

Array de objetos com nome, tipo, safra e estoque dos vinhos
Função para adicionar um vinho
filter para encontrar vinhos com estoque abaixo de 5 unidades
reduce para calcular o estoque total
Resultados exibidos automaticamente no console do navegador
